# My First Streamlit App

A small interactive app that greets visitors by name.

## Run it locally

```powershell
py -m pip install -r requirements.txt
streamlit run app.py
```

## Deploy it

Deploy this repository from [Streamlit Community Cloud](https://share.streamlit.io/), using `app.py` as the app file. Community Cloud will redeploy the app when you push changes to the connected GitHub repository.
